## Image Generation Notes

### Style Guidelines
- **Accessibility**: High contrast, clear subjects, no busy backgrounds
- **Consistency**: Similar color grading across category
- **Brand**: Neve26 watermark in corner (subtle)
- **Format**: WebP with PNG fallback

### Prompt Templates

**Athlete Action:**
```
Professional winter sports photography of [ATHLETE] performing [ACTION] during [EVENT]. Dynamic composition, snow spray visible, [NATIONALITY] team colors. High contrast, sharp focus on athlete. Photorealistic style.
```

**Venue:**
```
Panoramic view of [VENUE], [COUNTRY]. Snow-covered [COURSE TYPE] with [DISTINCTIVE FEATURE]. Alpine atmosphere, clear winter day. Professional sports photography style.
```

**Historical:**
```
Vintage-inspired sports illustration depicting [ERA] [SPORT]. Stylized composition showing [KEY ELEMENT]. Warm sepia tones blending to modern colors. Editorial illustration style.
```
