## How to Embed

### Instagram Post

1. Go to post on Instagram (web)
2. Click "..." menu → "Embed"
3. Copy embed code
4. Paste in article:

```html
<figure class="social-embed social-embed--instagram">
  <blockquote class="instagram-media"
    data-instgrm-permalink="https://www.instagram.com/p/POST_ID/"
    data-instgrm-version="14">
  </blockquote>
  <figcaption>Odermatt celebrates his fourth Adelboden victory.</figcaption>
</figure>
```

5. Add Instagram embed script once per page (before `</body>`):
```html
<script async src="//www.instagram.com/embed.js"></script>
```

### X/Twitter Quote (in text)

For quoting in article body:

```html
<blockquote class="athlete-quote">
  <p>"This one means more than ever. The crowd, the atmosphere - Adelboden is magic."</p>
  <cite>— Marco Odermatt, <a href="https://twitter.com/MarcoOdermatt/status/123">via X</a></cite>
</blockquote>
```

### X/Twitter Full Embed (visual)

```html
<figure class="social-embed social-embed--twitter">
  <blockquote class="twitter-tweet">
    <a href="https://twitter.com/MarcoOdermatt/status/123"></a>
  </blockquote>
  <figcaption>Odermatt's post-race reaction.</figcaption>
</figure>
```

Add Twitter widget script once per page:
```html
<script async src="https://platform.twitter.com/widgets.js"></script>
```

## Post-Race Workflow

```
1. Race ends
   ↓
2. Check athlete's Instagram (usually posts within 1-2 hours)
   ↓
3. If good visual → Embed Instagram post
   ↓
4. Check X/Twitter for reaction quotes
   ↓
5. If good quote → Add as blockquote with link
   ↓
6. Publish article with fresh social content
```

---

## Notes

- **Instagram**: Visual priority - celebration photos, podium shots
- **X/Twitter**: Quote priority - reactions, thanking fans
- **Verify handles**: Athletes sometimes change accounts
- **Check before embedding**: Ensure post is appropriate and not controversial
- **Captions**: Always add context in `<figcaption>`
